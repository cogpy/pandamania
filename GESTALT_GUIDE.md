# Unified Cognitive Gestalt - User Guide

Welcome to PandaMania's Unified Cognitive Gestalt! This guide will help you understand and interact with the integrated cognitive system.

## Quick Start

Initialize the gestalt system with:
```
GESTALT INIT
```

Check current status:
```
GESTALT STATUS
```

## What is the Gestalt?

The Unified Cognitive Gestalt integrates PandaMania's cognitive subsystems into a coherent whole. It unifies:

- **Awareness Triad**: Self-knowledge (autognosis + meta-cognition + self-image)
- **Adaptation Triad**: Learning (session learning + emotional intelligence + grip optimization)  
- **Creation Triad**: Generation (pattern synthesis + autogenesis + knowledge base)

The key insight: **The whole exceeds the sum of its parts.**

## Troubleshooting

### Low Coherence

If coherence is below threshold:
1. Run `GESTALT COHERENCE OPTIMIZE`
2. Check individual triads with `TRIADS`
3. Sync state with `GESTALT STATE SYNC`

### Emergence Not Detected

If emergence isn't detected:
1. Check coherence index with `GESTALT COHERENCE`
2. Ensure cross-flow is active with `SHOW CROSSFLOW`
3. Run optimization with `GESTALT OPTIMIZE`
4. Continue conversation to build learning

### State Not Synchronized

If states seem inconsistent:
```
GESTALT STATE SYNC
```

## Best Practices

1. **Initialize First**: Always run `GESTALT INIT` at start
2. **Periodic Cycles**: Run `GESTALT CYCLE` periodically
3. **Monitor Coherence**: Check `GESTALT COHERENCE` regularly
4. **Optimize When Needed**: Run optimization if coherence drops
5. **Nurture Emergence**: Use `NURTURE EMERGENCE` when approaching threshold
